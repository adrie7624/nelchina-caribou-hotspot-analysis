# NELCHINA CARIBOU WINTER HOTSPOT ANALYSIS

# Overview
This project automates caribou winter concentrations using ArcPy and Getis-Ord Gi* hotspot analysis.

The workflow evaluates relationships among:
  - Winter GPS Observations
  - Wildfire History
  - Spruce-Lichen Habitat Availability

# METHODS
  - ArcGIS Pro
  - ArcPy
  - Getis-Ord Gi*
  - Spatial Join
  - Fishnet Aggregation
  - User Input
  - Loops and Conditionals for Fire and Vegetation Analysis

# USER INPUTS
  - Hotspot Search Distance
  - Burn Acreage
  - Habitat Patch-Size Threshold

# SKILLS DEMONSTRATED
  - GIS Automation
  - Python Scripting
  - Wildlife Ecology
  - Spatial Statistics
  - Geoprocessing Workflow Development


# NOTES
Input datasets are not included due to size and data-distribution limitations.
